# 多平台媒体归档

Windows 桌面归档工具，用于保存本人账号、已获授权或公开可访问的社交媒体作品。

## 平台能力

| 平台 | 当前能力 | 登录 |
| --- | --- | --- |
| 抖音 | 主页批量、视频、图文、作品数据、评论及回复 | 建议在软件内登录 |
| TikTok | 公开主页或单条视频 | 免登录优先 |
| 微博 | 公开单条视频 | 免登录优先 |
| 小红书 | 公开视频笔记 | 免登录优先，图文原图适配中 |
| 快手 | 公开单链接实验性解析 | 免登录优先，不保证所有链接 |
| YouTube、哔哩哔哩、X / Twitter、Instagram | 公开链接解析 | 免登录优先 |

平台可能随时调整访问规则。免登录解析失败时，软件会显示实际错误，而不是创建空文件。

## 安装使用

1. 打开 [Releases](https://github.com/iTakatox/douyin-media-studio/releases)。
2. 下载最新版 `MediaArchiveStudio-Setup-*.exe`。
3. 双击安装，安装程序会创建桌面和开始菜单图标。
4. 打开“多平台媒体归档”。
5. 首次启动会自动安装下载组件，请保持网络连接。
6. 粘贴链接，先读取作品信息，再选择作品和保存目录并开始下载。

应用基于 Electron，后台服务静默运行，不会弹出命令行窗口。抖音登录窗口也在软件内部打开。

## 主要功能

- 自动识别链接所属平台
- Google Material 风格固定工作区，设置可折叠，作品表格自动占用剩余空间
- 免登录优先读取公开作品
- 读取作品信息后筛选并选择下载
- 抖音作品可不下载媒体，单独导出所选作品的评论和回复
- 系统文件夹选择窗口，也支持手动修改路径
- 显示日期、标题、类型、点赞、评论、收藏和分享数据
- 按标题、点赞数、评论数筛选，支持复制作品链接、反选和导出清单
- 支持停止扫描、下载或评论提取任务
- 状态轮询仅传输新增日志，避免长任务反复传输整份数据
- 读取任务超过 4 分钟无结果会自动停止并给出提示
- 抖音可分页提取评论及二级回复
- 自动生成 Excel 可打开的 `作品清单.csv`

通用平台输出结构：

```text
选择的保存位置/
  平台名称/
    作者名称/
      mp4/
        日期_作者_标题_作品ID_视频.mp4
      作品清单.csv
```

抖音继续使用独立的博主目录，并分别保存 `mp4`、`图片`、`评论` 和作品清单。

## 开发

环境要求：Windows、Node.js、Python 3.11+、Git。

```powershell
npm install
npm start
```

构建安装包：

```powershell
npm run dist
```

输出：

```text
release-electron/MediaArchiveStudio-Setup-*.exe
```
